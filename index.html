Perguntas que todo mundo faz.

O que eu recebo depois da compra?

Você recebe um link para baixar os arquivos do kit escolhido. Cada produto informa exatamente quais arquivos estão incluídos.

Preciso saber usar algum programa?

Não. Os kits foram pensados para começar rápido. Quando houver arquivo editável, a página do produto informa o aplicativo recomendado.

Posso usar os arquivos para vender meu próprio produto?

A licença pessoal permite uso nos seus posts, vídeos e identidade. Não é permitido revender ou redistribuir os arquivos originais.

Como funciona o pagamento?

O botão de compra será conectado ao seu checkout. Após você criar uma conta em uma plataforma de pagamento, basta inserir o link do produto no site.
